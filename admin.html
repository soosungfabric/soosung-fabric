카테고리 사진 관리

인스타그램 사진의 카테고리를 지정하고, 4개 카테고리 대표 이미지를 설정합니다. 이 화면에서 변경한 내용은 파일을 GitHub에 올린 후에만 실제 쇼룸에 반영됩니다.

사용 순서
① 대표 사진을 선택하고 대표 이미지 다운로드를 눌러 파일을 저장합니다(선택 사항).
② 아래 인스타그램 사진의 카테고리를 변경합니다.
③ 설정 파일 다운로드를 누릅니다.
④ GitHub 저장소 최상위에 category-config.json 및 다운로드한 대표 사진을 업로드합니다. 배포가 완료되면 쇼룸에 반영됩니다.
※ 이 페이지에는 로그인 보호 기능이 없습니다. 누구나 설정을 시험하고 파일을 내려받을 수 있지만, GitHub에 쓰기 권한이 없으면 사이트를 변경할 수 없습니다.

1. 대표 이미지 설정

원단 사진을 선택하면 정해진 이름으로 내려받을 수 있습니다. 파일은 GitHub의 최상위 폴더에 업로드하세요. 기존에 GitHub에 올린 이미지가 있다면 경로만 입력해도 됩니다.

2. 인스타그램 게시물 분류

각 사진에서 카테고리를 선택합니다. '자동 분류'를 선택하면 게시물의 해시태그·설명으로 분류됩니다. 새로 올라오는 게시물도 자동 분류됩니다.
