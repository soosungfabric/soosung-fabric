쇼룸 관리

메인 배너 사진, 카테고리 대표 이미지, 인스타그램 게시물 분류를 설정합니다. 이 화면에서 변경한 내용은 파일을 GitHub에 올린 후에만 실제 쇼룸에 반영됩니다.

사용 순서
① 메인 배너 모드를 선택하고, 새 사진을 사용할 경우 배너 사진 다운로드를 누릅니다.
② 카테고리 대표 사진과 게시물 분류를 원하는 대로 설정합니다.
③ 맨 아래 설정 파일 다운로드를 누릅니다.
④ GitHub 저장소 최상위에 category-config.json 및 다운로드한 사진을 업로드합니다. 배포가 완료되면 쇼룸에 반영됩니다.
※ 이 페이지에는 로그인 보호 기능이 없습니다. 누구나 설정을 시험하고 파일을 내려받을 수 있지만, GitHub에 쓰기 권한이 없으면 사이트를 변경할 수 없습니다.

1. 메인 배너 관리

쇼룸 첫 화면의 큰 배너를 변경합니다. 사진으로 교체를 선택하면 실제 원단 사진을 사용할 수 있습니다. 변경 후 사진 파일과 설정 파일을 모두 GitHub에 업로드하세요.

메인 배너 미리보기

새 사진을 선택하면 다운로드 버튼이 활성화됩니다. GitHub에 이미 업로드된 사진은 경로만 입력할 수 있습니다.

2. 카테고리 대표 이미지 설정

원단 사진을 선택하면 정해진 이름으로 내려받을 수 있습니다. 파일은 GitHub의 최상위 폴더에 업로드하세요. 기존에 GitHub에 올린 이미지가 있다면 경로만 입력해도 됩니다.

3. 인스타그램 게시물 분류

각 사진에서 카테고리를 선택합니다. '자동 분류'를 선택하면 게시물의 해시태그·설명으로 분류됩니다. 새로 올라오는 게시물도 자동 분류됩니다.

게시물을 불러오는 중…

기존 category-config.json 파일을 교체하면 배너·카테고리·분류 설정이 함께 적용됩니다.
